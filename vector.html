What is a vector? Each board game becomes a list of numbers — its "embedding" — that captures its characteristics. Here each game is a 7-dimensional vector: [userRating, bggAvg, bggBayes, bggRank_norm, numPlays_norm, yearPub_norm, weight_norm]. A Vector Database stores these arrays and can instantly find nearest neighbors using math (cosine similarity, Euclidean distance, dot product).

01
Build the Vector Store
For each game, extract numeric features and normalize them to [0, 1]. Stack every game's vector into a matrix.
// Each game → 7-dim vector vec = [ userRating / 10, // 0-1 bggAvg / 10, // 0-1 bggBayes / 10, // 0-1 1 - rank / maxRank, // inverted: lower rank = higher log1p(plays) / log1p(maxPlays), // log-scaled (year - 1950) / 75, // recency weight / 5, // 1-5 scale ];
02
Cosine Similarity
Two vectors that point in a similar "direction" are similar, regardless of magnitude. This is how semantic search works.
function cosine(a, b) { let dot = 0, magA = 0, magB = 0; for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; magA += a[i] * a[i]; magB += b[i] * b[i]; } return dot / (Math.sqrt(magA) * Math.sqrt(magB)); }
03
K-Means Clustering
Iterate: assign each point to nearest centroid, recompute centroid as mean of cluster. Repeat until assignments stabilize.
// Simplified K-Means loop for (let iter = 0; iter < 50; iter++) { // Assign each game to nearest centroid games.forEach(g => { g.cluster = argmin(centroids, c => euclidean(g.vec, c)); }); // Move centroids to cluster mean centroids = clusters.map(c => meanVector(c.games.map(g => g.vec))); }
04
PCA Projection
Principal Component Analysis finds the 2 axes of most variance. We project every 7D vector onto these 2 axes to visualize the data.
// Power iteration for top 2 PCs function pca2d(matrix) { const centered = center(matrix); const pc1 = powerIterate(centered); const pc2 = powerIterate( deflate(centered, pc1)); return matrix.map(v => [ dot(v, pc1), dot(v, pc2) ]); }
05
Real Vector DBs
Production systems (Pinecone, Weaviate, Chroma, pgvector) use ANN indexes (HNSW, IVF) to search billions of vectors in milliseconds — far faster than our brute-force loop.
// Production usage (Pinecone example) const results = await index.query({ vector: gameEmbedding, topK: 10, includeMetadata: true }); // Returns nearest neighbors in ~1ms // even with millions of vectors!
06
Feature Engineering
The quality of your vectors depends on choosing good features. Here we use 7 numeric dimensions. Real ML systems use 384–1536-dim embeddings from neural networks.
// Our 7 features: // [0] userRating — how YOU rated it // [1] bggAvg — community avg // [2] bggBayes — Bayesian weighted // [3] rank_norm — BGG overall rank // [4] plays_norm — your play count // [5] year_norm — publication year // [6] weight_norm — complexity (1-5)
