Retrieval-Augmented Generation (RAG) — the most popular LangChain pattern. Step 1: Retriever scores your collection with keyword + feature matching. Step 2: StuffDocumentsChain injects the top docs into the prompt context. Step 3: LLMChain generates a grounded answer with citations.
LangChain Agents use an LLM as a reasoning engine to choose which tool to call and in what order. The agent sees a set of tools, thinks ("Thought"), picks a tool ("Action"), observes the result, and loops until it can answer. This is the ReAct pattern (Reasoning + Acting).
