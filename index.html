About These Projects

🎲 Board Game Data Tools & Visualization Suite

A collection of interactive tools and pages exploring board game data, collection analytics, and play statistics through creative data visualization and analysis.

Passionate about: Board games, data analysis, and building innovative tools to explore data in creative ways.

Welcome to the Board Game Data Analytics Suite! This is a curated collection of tools and interactive applications built around my passion for board games, data analysis, and creative problem-solving through data visualization.

Each project in this suite represents a different approach to exploring board game data—from collection management and play tracking to statistical analysis and performance comparisons.

🎮 Collection Tools
Browse, manage, and analyze your personal board game collection with integrated BGG (BoardGameGeek) data, library comparisons, and detailed statistics.
📊 Play Statistics
Track play history, view detailed statistics about your gaming sessions, and export data in multiple formats for further analysis or sharing.
📈 Data Visualization
Interactive visualizations including distribution charts, ranking comparisons, complexity analysis, and play time breakdowns across your collection.
🔧 Built With
Vanilla JavaScript, HTML5, CSS3, Python, and BGG API integration. All projects are optimized for mobile and desktop experiences.
💡 My Passion
I'm passionate about board games and discovering new insights through data analysis. These tools showcase different ways to transform raw data into meaningful, interactive experiences that help you understand your gaming habits and collection better.
📮 Get in Touch
Questions, suggestions, or want to collaborate? Find me at @sportomax on social media or GitHub.
