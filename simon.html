ℹ️ How to Play

• Watch the sequence of board game covers flash

• Repeat the sequence by clicking the games in order

• Each round adds one more game to the sequence

• Press SPACE or click Pause button to pause

• Try to get the highest score possible!

Game Selection Modes:

- Random: Games are automatically chosen

- Choose: Select your favorite games to use

Change Games Options:

- Same games all game: Use the same set throughout

- Change each round: New games every round

- Change each new game: New games when you restart

Choose Your Games

Select 4 games to use in Simon

⏸️ PAUSED

Press SPACE or click Resume to continue
