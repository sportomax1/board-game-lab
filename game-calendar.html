A game for every day.

Every eligible owned game gets exactly one date, starting today. Each day's percentile selector is applied to the remaining unscheduled games, using BGG complexity weight first, rating descending as the first tiebreaker, and BGG ID ascending as the final tiebreaker. The calendar stops when the collection is exhausted—no repeats.

Calendar settings

Defaults to “sportomax”. The value is saved only in this browser.

A percentile is calculated against the remaining games. For example, a one-day 0% cycle always takes the easiest remaining game, producing an easiest→hardest calendar. Changing cycle length seeds evenly spaced selectors that you can edit below.

Cycle selectors
The app requests only games marked Owned, excludes board-game expansions, and uses BGG Thing API statistics for complexity weight and average rating. Games with no published complexity weight are omitted. Percentile index uses the lower deterministic position: floor((remaining − 1) × percentile / 100).
