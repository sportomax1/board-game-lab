Run the exporter on your own Board Game Arena finished-game history page. The player ID changes the BGA link; the script reads whichever account's history is displayed there. It does not run on this dashboard.

Open BGA finished-game history ↗
https://boardgamearena.com/gamestats?player=85550432&opponent_id=0&finished=1
  1. Open the linked BGA page and sign in if needed. Confirm the player history displayed is the one you intend to export.
  2. Open Developer Tools → Console (F12 or Ctrl+Shift+J on Windows; Option+Command+J in Chrome on Mac).
  3. Copy the script below, paste it into that BGA page's console, and press Enter. If Chrome blocks console pasting, follow its on-screen instructions only after reviewing the script.
  4. Once it finishes, upload the downloaded bga-full-games-history-YYYY-MM-DD.csv using the file chooser above.
The script downloads a CSV of the currently displayed history. The clipboard copy is optional.
