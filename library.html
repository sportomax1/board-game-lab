Data sources and loading details

📂 Local XML Files

  • library_sportomax.xml - My collection (primary source)
  • library_bgg.xml - BGG Convention games
  • library_dte.xml - DTE Convention games
  • library_dtw.xml - DTW Convention games

🌐 BGG API Enrichment

After loading local files, the app fetches additional data from BoardGameGeek API:

  • Endpoint: /api/bgg-helper?endpoint=thing&id=...
  • Fields loaded:
    • ⏱️ Playing time (playingtime)
    • ⚖️ Weight/complexity (boardgameweight)
    • 🎯 Best player count (poll-summary → bestplayers)
    • 👍 Recommended player counts (poll-summary → recommendations)
    • 🖼️ Thumbnail images

🔄 Loading Process

  1. Load 4 local XML files in parallel
  2. Parse and merge game data from all sources
  3. Sort by "desire to play" (custom priority)
  4. Batch fetch BGG API data for enrichment (thumbnails, weight, etc.)
  5. Update cards dynamically as API data arrives

💡 Features

  • 🎨 Color-coded convention badges
  • 🔍 Filter by name, player count, time, weight
  • 📋 Click badge to see raw XML data
  • 🎲 Click "BGG" icon to see full API response
  • 🔗 All games link to BoardGameGeek
