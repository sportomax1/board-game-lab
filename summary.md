# Application Summary

## 🎬 videos.html - Game Video Browser
A dedicated tool for discovering video content related to your board game collection. It allows users to load their BGG collection and automatically fetches associated videos (reviews, instructional, previews, etc.) for each game. Features include a progress bar for API loading, search and sort functionality (by name or video count), and a responsive grid layout of game cards showing video counts.

## 🏪 marketplace.html - Virtual Marketplace
An interactive marketplace interface for browsing games available for sale or trade. Users can load listings, filter by various criteria, and view detailed information about each game. The app includes a settings modal for configuring data sources and preferences, with a clean, card-based layout for displaying game listings and their prices or trade status.

## 📦 inventory.html - Inventory Management
A comprehensive inventory tracking system for board games. It provides a detailed view of the collection with status indicators, location tracking, and management features. The interface allows for quick searching and filtering of the inventory, making it easier to audit the collection or find specific items.

## 📚 collection.html / collectionapi.html - Collection Browser
These tools provide a rich interface for browsing a BoardGameGeek collection. `collectionapi.html` is a newer, API-driven version that allows users to filter by status (Own, Want to Play, etc.), sort by various metrics (Name, Year, Rating), and view aggregate statistics about the collection. It serves as a central hub for visualizing and exploring one's personal library of games.

## 🏛️ library.html - Library Management
Designed for managing larger collections, possibly for a lending library or event. It likely includes features for checking games in and out, tracking availability, and organizing games by shelf or location. Variants like `library_bgg.html` and `library_dte.html` suggest integration with different data sources or specific event libraries.

## 🏷️ vfm.html - Virtual Flea Market
A suite of tools (including `vfm_new.html`, `vfm_old.html`, and XML data files) for managing Virtual Flea Market data. These apps are likely used to visualize and manage game sales for conventions, allowing users to browse available items, check prices, and see what's being sold in a "cascade" or list format.

## ⏱️ hunt.html - Scavenger Hunt
A gamified way to explore a collection. Users can play in Solo or Competition mode, where they must find specific games from their collection within a configurable time limit (10-300 seconds). It adds a fun, interactive element to browsing, testing the user's knowledge of their own library.

## 🔍 thingapi.html - BGG Thing Lookup
A developer-focused utility for querying the BoardGameGeek API directly. Users can enter a BGG Thing ID to fetch and view the raw XML response for a specific game. This is useful for debugging, verifying data, or quickly checking the metadata available for a particular title.

## 🎥 credits.html - Arcade Credits Roller
A visual showcase tool that displays game covers in an animated, arcade-style rolling credits format. It supports both RAWG (video games) and BGG (board games) data sources. Users can filter the displayed games and choose from different animation styles like "Classic Roll", "Fireworks", or "Image Rain".

## 🎲 menu.html - Player Count Menu
A specialized utility for finding the best games for a specific number of players. Users enter their BGG username and a desired player count, and the app filters their collection to show games that are "Best", "Recommended", or "Supported" for that count, based on BGG community voting data.

## 📊 plays.html - Play Statistics
An analytics dashboard for visualizing play history. It likely connects to BGG play logs to show trends over time, most played games, player wins, and other interesting statistics derived from recorded gaming sessions.

## 🏆 bracket.html - Tournament Bracket
A tool for running single or double-elimination tournaments with games from the collection. It allows users to pit games against each other in a bracket format to determine a "winner" or favorite game, providing a structured way to rank or choose games.

## ⚔️ matchup.html - Game Matchups
Similar to the bracket tool, this likely focuses on head-to-head comparisons between games. It may be used for "Face-off" style voting or ranking, helping users decide between two specific titles or rank a subset of their collection through pairwise comparisons.

## 📝 draft.html - Game Draft
A utility for simulating a draft process with board games. This could be used for distributing games among players for a game night, creating a "fantasy" collection, or simply as a fun way to select games to play from a larger pool.
