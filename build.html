Standard Deck Generator

This tool generates a full 52-card deck scaled exactly for 8.5" x 11" paper. Each card is 2.5" x 3.5" with standard rounded corners. There are 9 cards per page.

Tip: Set "Margins" to "None" and "Scale" to "100%" (Default).

Cricut Maker 3 Instructions

1. Get the Software

Download Cricut Design Space for free from design.cricut.com. It works on Windows, Mac, iOS, and Android.

2. Prepare Your Cut File

  1. Open Design Space and click "New Project".
  2. Click "Shapes" on the left toolbar and select a Square.
  3. Unlock the size (padlock icon) and set dimensions to match your card size (e.g., 2" x 3" for YOLO).
  4. Duplicate the rectangle to match the grid (e.g., 4 columns, 3 rows).
  5. Position the rectangles to match the print layout:
    Start X: 0.4" (Left Margin)
    Start Y: 0.15" (Top Margin)
    Gap: 0.1"
  6. Select all rectangles and click "Attach" (bottom right). This keeps them in place.
  7. Click "Make It".

3. Print & Cut (Full Page Hack)

  1. Print: Print this page on your cardstock using the "Print Deck" button above. Ensure Scale is 100%.
  2. Prepare Mat: Place the printed sheet on a LightGrip (Blue) mat, aligned exactly to the top-left corner (0,0).
  3. Cut: In Design Space, select your material (e.g., "Cardstock"). Load the mat into the machine and press the Go button.
Tip for Compact Layout: The cards are printed vertically (2" x 3") but the content is rotated. In Design Space, create 2" x 3" vertical rectangles.
