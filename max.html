8-Phase Search Algorithm

Maximum ID finder uses 8 progressive phases to efficiently locate the highest BGG Thing ID, never checking IDs below validated maximum.

Phase 1: Powers of 10

Tests checkpoint IDs: 1, 10, 100, 1K, 10K, 100K, 1M, 10M, 100M, 1B

✓ 10 API calls in parallel • Identifies magnitude of max ID

Phase 2: Leading Digit Sweep

Tests multiples of magnitude (1x, 2x, 3x...9x) above validated max

✓ Up to 9 checkpoints • Identifies next digit

Phase 3: Second Digit Refinement

Tests 10x magnitude variations for second digit

✓ Up to 90 checkpoints • 100x parallel batching

Phase 4: Third Digit Refinement

Tests 1x magnitude variations for third digit precision

✓ Up to 900 checkpoints • 100x parallel batching

Phase 5: Hundred-Step Sweep

Tests +100, +200, +300...+10000 checkpoints above validated max

✓ ~100 checkpoints • Early exit if 30% checked with no hits

Phase 6: Ten-Step Sweep

Tests +10, +20, +30...+1000 checkpoints above validated max

✓ ~100 checkpoints • Early exit if 30% checked with no hits

Phase 7: Dense Batch Scan

Sequential batch scanning using 20 IDs per batch, only as final resort

✓ Stops after 30 consecutive empty batches • Handles ID gaps safely

Phase 8: Final Verification

Spot checks at +1K, +10K, +100K, +1M to ensure no scattered higher IDs

✓ If higher ID found, restarts search from new max

🎯 Key Efficiency Features

  • ✓ Never checks below validated max throughout all phases
  • ✓ 100x parallel processing on checkpoint phases
  • ✓ Early exits when sparse sweeps show no hits
  • ✓ Dense scanning delayed until Phase 7 (sparse phases exhausted)
  • ✓ Handles gaps like ID 33 missing but 34 existing
  • ✓ Estimated ~1,200 API calls vs 40K+ sequential checks
