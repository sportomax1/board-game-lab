App Logic Details

Overview

This app helps you organize your board game collection into Kallax shelves by analyzing game box measurements and intelligently fitting them into cube spaces.

Tab 1: Collection View

  • Data Loading: Fetches your BGG collection using the v2 API with own=1 parameter
  • Parallel Processing: Uses 100x parallel processing to load version information for all games simultaneously
  • Version Details: Displays each version with name, language, height, width, length, and weight
  • Collapsible Cards: Games are shown as cards that can be expanded to see all versions (default shows count)
  • Thumbnails: Each version shows its own thumbnail image
  • Filters:
    • Hide versions with empty measurements
    • Hide non-English versions (versions without language specified are kept)

Tab 2: Measurement Selection

  • Most Common Measurement: Calculates which height/width/length combination appears most frequently across versions
  • Tie Breaking: If multiple measurements appear equally often, selects the median based on cubic volume
  • One Game Per Card: Shows one card per game with the selected measurement
  • Override Capability: Click on a game to manually select a different version's measurements
  • Version Thumbnail: Displays the thumbnail from the version that has the selected measurement
  • Real-time Updates: Automatically updates when filters change in Tab 1

Tab 3: Shelf Fitting Algorithm

Kallax Dimensions: Default 13" wide × 13" tall × 15" deep (customizable)

Step-by-Step Algorithm:

  1. Dimension Tagging:
    • For each game, identify the smallest dimension → "min"
    • Identify the middle dimension → "mid"
    • The largest dimension is not tracked
  2. Sorting: Sort all games by "mid" measurement from highest to lowest
  3. Vertical Filling:
    • Start with the tallest "mid" game
    • Stack games vertically in the cube
    • Continue until the "min" dimension exceeds the cube width
  4. Fill Gaps:
    • When space runs out, search remaining games for smaller "min" values that fit
    • Continue filling until no more games fit vertically
  5. Horizontal Stacking:
    • Calculate remaining space above vertical stack (13" - total mid)
    • Look for games that can fit horizontally in this space
    • Place games where their "mid" ≤ remaining space
  6. Next Cube: When no more games fit, move to the next cube and repeat with the largest remaining "mid"

Interactive Features:

  • Visual Scale: Game boxes are shown to scale within each cube
  • Click to Modify: Click any game in the shelf to change its measurement or hide it
  • Real-time Recalculation: Any change instantly recalculates the entire shelf layout
  • Remove Games: Games can be removed from the shelf on any tab

Technical Details

  • API Calls: Uses BGG XML API2 collection and thing endpoints
  • Retry Logic: Automatic retry with exponential backoff for 202 responses
  • Batch Processing: Groups API calls into batches of 20 IDs, processes 100 batches in parallel
  • Measurement Conversion: Converts cm to inches for shelf calculations (1 inch = 2.54 cm)
  • Volume Calculation: Cubic volume = width × length × height (in cm³)
