Get started

Analyze your Board Game Arena audience

Run the attached exporter on the BGA audience page, then import the CSV to explore monthly totals, individual games and performance trends.

No BGA login required here
01 · Open Audience

Sign into boardgamearena.com/audiencelist and choose the starting month.

02 · Run exporter

Copy the console script, press F12 → Console on BGA, paste, then enter how many months back (1–120).

03 · Import your CSV

Paste its CSV, upload the downloaded file or read the clipboard. Re-import later to merge new months.

Import monthly audience data

Paste or upload the exporter CSV

The CSV must include month and game along with the metrics from the attached exporter. Quoted commas and multiline fields are supported. Duplicate game/month rows are merged.

“Replace existing months” replaces rows for each month in the imported file; other months remain saved. Leave unchecked to merge by month and game. The original CSV is not uploaded anywhere.
