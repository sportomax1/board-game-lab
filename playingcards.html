Cricut Maker 3 - Print & Cut Guide

Maker 3 recommendations for Print-then-Cut in Cricut Design Space.

  1. Print Then Cut area: Supports approx 6.75" x 9.25". For full-page layouts, split into sheets or print and trim before cutting.
  2. Export / Bleed: Export each sheet as PNG/PDF at 300 DPI. Add 0.02-0.125" bleed. Do not remove registration marks.
  3. Upload to Design Space: Upload and choose Print Then Cut. Place on 8.5" x 11" canvas then Make It.
  4. Mat Required: Print Then Cut always requires a mat. Use StandardGrip for sticker paper or cardstock.
  5. Recommended Materials:
    • Printable Sticker / Vinyl: Fine-Point Blade, Pressure: Default, Passes: 1
    • Light-Medium Cardstock (65-100 lb): Fine-Point Blade, Pressure: More, test first
    • Heavy Cardstock (110-130 lb): Fine-Point Blade, StrongGrip mat
    • Chipboard: Knife Blade, StrongGrip mat, increase passes as needed
  6. Calibration: Run Print-then-Cut calibration in Design Space if cuts are misaligned. Always test first.
  7. Alignment: Leave 0.125-0.2" safety margin to account for printer shift.
