DEPENDENCY PATTERNS
================================================================================

1. CENTRALIZED API PATTERN:
   - Most HTML files → /api/bgg-helper.js for BoardGameGeek data
   - Reduces direct API calls, improves security via Vercel serverless

2. DATA FILE PATTERN:
   - vfm.html loads multiple VFM XML files (switchable by dropdown)
   - Private collection apps load private_all.xml or private_own.xml
   - Library apps load library_*.xml files

3. DOCUMENT HUB PATTERN:
   - index.html and master_index.html act as application directories
   - Both reference all HTML application files and data files

4. FIREBASE INTEGRATION:
   - checkout.html, matchup.html use /api/firebase-config for real-time DB
   - matchup.html also uses /api/get-password for authentication

5. IMAGE PROXY PATTERN:
   - Multiple apps use /api/image-proxy to load game images
   - Prevents CORS issues from external image URLs

6. DRAFT/EXPERIMENTAL APPS:
   - /draft directory contains experimental/alternate versions
   - welcome.html uses separate welcome.js and welcome2.js files
   - draft/all-in-one.html loads app.js and external libraries

7. EXTERNAL LIBRARIES:
   - Most HTML files import: https://cdn.tailwindcss.com (CSS framework)
   - Some use: html2canvas, canvas-confetti, PapaParse (CSV parsing)
   - Firebase modules imported from https://www.gstatic.com/firebasejs/
